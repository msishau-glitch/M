# Wedding Invitation

A simple mobile-first digital wedding invitation built with HTML, CSS and vanilla JavaScript.

## Structure

- `index.html` contains the semantic page structure.
- `css/style.css` contains the design system and responsive styling.
- `js/script.js` contains navigation and reveal animation logic.
- `assets/images` stores photo and artwork assets.
- `assets/icons` stores any icons used in the invitation.
