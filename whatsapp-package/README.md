## Distribution flow

1. Send a personal WhatsApp message with the invitation link.
2. Share the static image or status version for visibility.
3. Use the RSVP reminder after guests have had time to respond.

## Notes

- The public invitation keeps guest details private.
- No private API keys or database credentials are exposed.
- The RSVP form remains separate from any admin dashboard or data view.
